# 未來科技校園 RPG（2D Top-Down 角色走動冒險雛型）

這是一個在瀏覽器執行的 **2D Top-Down RPG（俯視角角色移動冒險遊戲）**。
玩家直接控制**實際站在大溪國中校園地圖上的 RPG 角色**，於校園林蔭道與走道間自由探索，前往科技館與「數字研究員（數學老師）」NPC 進行距離感應互動，接取「能源核心修復」任務，完成 5 題原創數學任務關卡，並產出概念層級的匿名學習歷程診斷。

---

## 遊戲核心操作方式

* **電腦鍵盤**：
  * 移動：`W`（上）、`S`（下）、`A`（左）、`D`（右） 或 方向鍵（`↑` `↓` `←` `→`）。
  * 支援 8 向斜向平滑移動（向量正規化，不超速）。
  * 具備 4 向角色朝向與即時步態雙腳交替踏步動畫。
  * 互動：走近 NPC 老師（距離 < 85px）會出現浮動提示，按下 `E` 鍵或 `Space` / `Enter` 開啟對話。
* **平板／手機觸控**：
  * 左下方：**虛擬觸控搖桿（Virtual Joystick）**，以手指拖曳自由操控方向。
  * 右下方：**「互動 [E]」動作按鈕**，靠近 NPC 老師時自動高亮發光，點擊立即開啟對話。
* **物理與鏡頭系統**：
  * 包含嚴格的校園建築與外圍牆 AABB 實體碰撞盒，角色絕不穿牆，撞牆時具備順暢的沿牆滑動（Wall Sliding）。
  * 2D 鏡頭以玩家角色為中心平滑跟隨移動，並限制於地圖邊界之內。
  * 右上角配置即時雷達小地圖（Minimap），顯示玩家即時座標與目標位置。

## 啟動與測試

1. 安裝套件：`npm install`（或 `pnpm install`）
2. 啟動本機開發伺服器：`npm run dev`（開啟瀏覽器即可直接遊玩）
3. 執行單元與整合測試：`npm test`
4. 輸出正式生產包：`npm run build`

---

## 資安與個資規範

本雛型使用原創數學題目與匿名、僅存在瀏覽器記憶體中的學習事件。它不收集學生姓名、學號、照片或聯絡資料，也不含 API 金鑰或真實教師肖像，完全符合校園 AI 倫理與資通安全管理法規。
地圖依據大溪國中 115 學年平面圖重新繪製；數字研究員為原創虛構 NPC。
